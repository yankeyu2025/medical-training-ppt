# 医学培训课件：心力衰竭与抗精神病药物相关心脏不良反应

此仓库存放生成31页中文医学培训PPT的Python脚本。采用白底、蓝灰医学风格，内容覆盖心衰症状/体征/治疗目标，以及QT延长、心肌炎、药物风险比较、监测和处置。

## Codex 中使用

打开此仓库，在Codex里运行：

```bash
python -m pip install python-pptx
python build_ppt.py
```

生成文件：`Heart_Failure_Antipsychotics_Training.pptx`。在Codex文件列表中下载，或在本地运行后直接打开。
